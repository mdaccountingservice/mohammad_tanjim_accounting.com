# Mohammad Tanjim — Accountant & Bookkeeper Portfolio

A responsive bilingual portfolio website. English appears first, followed by the Arabic version. The profile photo is included in `assets/profile.jpg`.

## Run locally
Open `index.html` in a web browser. No build tools are required.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, for example `accountant-portfolio`.
2. Upload `index.html`, `README.md`, and the complete `assets` folder (keep the folder structure unchanged).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for the Pages deployment. GitHub will show the published website URL in Settings → Pages.
